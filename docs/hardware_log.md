# EEG Cap & Electrode — Build Log / Lessons Learned

## Cap material
- **Silicone swim caps: poor for electrode recording.** Slippery (electrodes
  slide), non-porous, hard to mark/modify, and don't fit snugly in many areas.
  - Salvage use: cut into an elastic band to press ground/reference electrodes
    in place. (Good repurposing, not good as the main cap.)
- **Cotton beanie: much better base.** Grips electrodes, breathable, takes
  markings. Downsides: knit fabric makes clean holes hard; tape sticks but isn't
  ideal on it.

## Electrode fit / stability
- Knit holes let electrodes slide back in. **Velcro behind the electrode
  minimizes slide and holds readings solid** — currently the key stabilizer.
- Foam padding behind (with velcro) considered, but marginal benefit so far —
  deprioritized.
- **Hat worn over the beanie** for extra pressure (last session) — testing.

## Reference / ground
- Elastic band (from cut swim cap) to hold ground electrodes more firmly.
- **Open question: reference/bias contact is still the most likely limiter** —
  not yet given full prep consistently.

## Gel application
- **Syringe method FAILED — paste too viscous to push through a syringe.**
- Working method: pre-part hair, pre-gel scalp sites, then seat cap so electrodes
  grip scalp (not hair). Improved contact on at least one channel.

## Results so far
- Best session: velcro + elastic band → clean alpha response (eyes-closed ratio
  ~1.7 on two occipital channels). PROVES the rig can capture real brain signal.
- Persistent issue: ~80%+ of raw power above 60 Hz on most channels = high
  electrode impedance / reference contact. Alpha detectable but noise-swamped.
- Results swing session to session → repeatability not yet achieved.

## Next / ideas
- FREEZE the setup; run repeated eyes-closed trials to test reproducibility
  before changing anything else.
- Give reference/bias full prep (alcohol + abrasion + gel + firm contact).
- Change ONE variable at a time; keep annotating every session.
- Consider NuPrep / better gel once mechanical setup is stable.
- Check dashboard for per-channel impedance readout (live feedback loop).
