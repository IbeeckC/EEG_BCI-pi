03 / tools

Libraries & documentation

The software pillar was built on the Python scientific stack. The SciPy signal-processing functions below were the specific tools used to design and apply the project's filters.

MNE-Python

EEG data loading, PhysioNet dataset access, epoching, and CSP.

mne.tools

scikit-learn

LDA classifier, pipelines, and leak-free cross-validation.

scikit-learn.org

SciPy signal

Filter design and application for the real-time / causal filtering work.

scipy.signal

pandas

Loading and handling the PiEEG recording CSVs.

pandas.pydata.org

NumPy

Array math underlying every stage of the pipeline.

numpy.org

Matplotlib

All spectra, scalp maps, and result plots.

matplotlib.org

PiEEG-16

The acquisition board and its recording/streaming software.

pieeg.com

PhysioNet

The EEG Motor Movement/Imagery dataset the pipeline was validated on.

physionet.org

SciPy signal functions used

  • butter — Butterworth filter design
  • sosfilt — apply an SOS filter (causal, streaming-safe)
  • sosfilt_zi — initial conditions for SOS streaming
  • lfilter_zi — initial conditions for IIR streaming
  • sosfreqz — frequency response of an SOS filter
  • scipy.signal — full signal-processing reference
